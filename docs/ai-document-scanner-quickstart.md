# AI Document Scanner - Quick Start Guide

Get up and running with the AI Document Scanner in just a few minutes! This guide will walk you through the essential steps to start scanning documents and extracting compliance clauses.

## Prerequisites

Before you begin, make sure you have:
- ✅ A Compliance Explorer account
- ✅ Access to a project within your organization
- ✅ Documents ready for scanning (PDF, DOCX, DOC, TXT, RTF)

## Step 1: Access the Document Scanner

1. **Log into Compliance Explorer**
   - Navigate to your application URL
   - Sign in with your credentials

2. **Navigate to Document Scanner**
   - Go to your project dashboard
   - Click on the "Document Scanner" tab
   - Or use the direct URL: `/{org-slug}/{project-slug}/document-scanner`

## Step 2: Upload Your First Document

### Option A: Drag and Drop
1. **Prepare your document**
   - Ensure it's in a supported format (PDF, DOCX, DOC, TXT, RTF)
   - Keep file size under 50MB for best performance

2. **Upload the document**
   - Drag your file from your computer
   - Drop it onto the upload area
   - The system will automatically start processing

### Option B: Click to Browse
1. **Click the upload area**
   - Click anywhere in the upload zone
   - Select your document from the file browser
   - Click "Open" to start upload

## Step 3: Monitor Progress

Once uploaded, you'll see:
- **Progress bar**: Shows processing percentage
- **Status message**: Current processing stage
- **Estimated time**: How long until completion
- **Real-time updates**: Live progress information

### Processing Stages
1. **Uploading** - File is being uploaded to our servers
2. **Validating** - Checking file format and integrity
3. **Extracting** - Converting document to text
4. **Analyzing** - AI is detecting compliance clauses
5. **Deduplicating** - Removing similar clauses
6. **Finalizing** - Preparing results for display

## Step 4: Review Results

When processing is complete, you'll see:

### Results Summary
- **Total clauses found**: Number of detected clauses
- **Processing time**: How long the scan took
- **File information**: Size, pages, format
- **Confidence scores**: Overall accuracy of detection

### Clause Details
Each detected clause shows:
- **Clause text**: The actual clause content
- **Confidence score**: How accurate the detection is (0-100%)
- **Clause type**: Category (compliance, liability, etc.)
- **Page number**: Where it was found in the document
- **Line number**: Specific location in the document

## Step 5: Take Action

### Available Actions
1. **View Details**: Click on any clause to see full details
2. **Export Results**: Download results in various formats
3. **Save to Project**: Add clauses to your project library
4. **Share Results**: Generate shareable reports
5. **Start New Scan**: Upload another document

## Common Scenarios

### Scenario 1: Quick Compliance Check
**Goal**: Quickly check a contract for compliance clauses

**Steps**:
1. Upload your contract document
2. Wait for processing (1-3 minutes for typical documents)
3. Review high-confidence clauses (80%+ confidence)
4. Export results for further analysis

### Scenario 2: Batch Document Review
**Goal**: Process multiple documents efficiently

**Steps**:
1. Upload first document
2. While processing, prepare next document
3. Review results as they complete
4. Compare clauses across documents
5. Export combined results

### Scenario 3: Template Creation
**Goal**: Create clause templates from existing documents

**Steps**:
1. Upload documents with good clause examples
2. Review and validate detected clauses
3. Save high-quality clauses as templates
4. Use templates for future document analysis

## Tips for Best Results

### Document Preparation
- **Use text-based PDFs**: Avoid scanned images when possible
- **Clean formatting**: Remove unnecessary formatting
- **Complete pages**: Ensure all content is included
- **High contrast**: Make sure text is clearly readable

### Upload Strategy
- **Start small**: Test with smaller documents first
- **Check file size**: Keep under 20MB for optimal performance
- **Verify format**: Ensure supported file types
- **Backup originals**: Keep copies of original documents

### Results Review
- **Focus on high confidence**: Prioritize 80%+ confidence scores
- **Verify accuracy**: Review all detected clauses
- **Check context**: Ensure clauses are complete and accurate
- **Export important results**: Save valuable findings

## Troubleshooting

### Upload Issues
**Problem**: File won't upload
**Solutions**:
- Check file size (max 50MB)
- Verify file format is supported
- Try a different browser
- Check internet connection

### Processing Issues
**Problem**: Processing takes too long
**Solutions**:
- Large files take longer (normal)
- Check server status
- Try smaller document sections
- Contact support if persistent

### Results Issues
**Problem**: No clauses detected
**Solutions**:
- Check document quality
- Try different document sections
- Verify document contains compliance content
- Lower confidence threshold in settings

## Quick Reference

### Supported Formats
- **PDF**: `.pdf` (best results)
- **Word**: `.docx`, `.doc`
- **Text**: `.txt`
- **Rich Text**: `.rtf`

### File Limits
- **Maximum size**: 50MB
- **Recommended**: Under 20MB
- **Processing time**: 1-15 minutes depending on size

### Confidence Levels
- **High**: 80-100% (very reliable)
- **Medium**: 60-79% (moderately reliable)
- **Low**: 0-59% (review carefully)

### Common Clause Types
- **Compliance**: Regulatory requirements
- **Liability**: Responsibility and indemnification
- **Termination**: Contract ending conditions
- **Confidentiality**: Privacy and NDA clauses
- **Payment**: Financial terms and conditions
